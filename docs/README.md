# Índice da documentação

- `requisitos/`: regras obrigatórias da versão demonstrativa;
- `arquitetura/`: estrutura técnica e separação dos ambientes;
- `seguranca/`: controles preservados e adaptações da Vercel;
- `deploy/`: preparação e publicação, sempre mediante autorização;
- `repositorio/`: política Git, arquivos permitidos e auditoria;
- `operacao/`: uso e reinicialização segura da demo;
- `sprints/`: escopo, decisões, arquivos e testes de cada evolução.

O código permanece organizado por domínio Django. Uma sprint registra mudanças,
mas não cria cópias paralelas dos mesmos módulos.
