# Política do repositório demo

- histórico Git novo e independente;
- nenhum remote configurado antes da autorização;
- somente código, migrations, testes e documentação sanitizados;
- `.env`, bancos, dumps, logs, documentos e chaves sempre ignorados;
- varredura de conteúdo e histórico antes de cada publicação;
- referências ao contrato e ao repositório reais são proibidas;
- GitHub e deploy somente após revisão do usuário.
