# Decisões — Sprint 69

1. O recurso é conciliação manual; nenhuma API ou credencial externa foi usada.
2. “Registrado” ou “Atualizado” exige uma referência informada pelo usuário.
3. “Não aplicável” exige justificativa.
4. O alerta só aparece quando o controle foi marcado como necessário e ainda
   está pendente.
5. O registro local nunca é apresentado como comprovação de que o sistema
   oficial foi atualizado.
