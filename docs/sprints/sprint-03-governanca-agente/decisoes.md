# Decisões da Sprint 03

1. Foi criado somente `CLAUDE.md`. `AGENTS.md` (Codex) será criado apenas se o
   Codex passar a ser usado, para evitar dois arquivos divergentes.
2. Os documentos sugeridos no curso (`REQUISITOS.md`, `ARQUITETURA.md`,
   `EVIDENCIAS.md`, `DECISOES.md`) não foram duplicados na raiz: o projeto já
   os mantém em `docs/` e em cada sprint. O `CLAUDE.md` indica onde estão.
3. O registro de evidências continua em `testes.md` de cada sprint.
4. O `CLAUDE.md` não contém nomes pessoais nem dados reais, para manter a
   auditoria do repositório aprovada.
