# Escopo da Sprint 06 — Identidade visual

## Objetivo

Dar ao sistema uma identidade visual própria, conforme os itens M1, M2, M3 e
M5 do diagnóstico da Sprint 04.

## Itens

| Item | Entrega |
|---|---|
| M1 | Logotipo SVG (opção C — barras de acompanhamento) no topo e no login; nome "FiscalSema" com o subtítulo "Gestão contratual" |
| M2 | Favicon SVG (ícone da aba do navegador) |
| M3 | Ícones SVG próprios no menu lateral, no lugar de caracteres de texto |
| M5 | Faixa de demonstração em âmbar com texto escuro (continua sempre visível) |
| — | Títulos das abas: "FiscalSema Light" → "FiscalSema" |

## Limites

- sem bibliotecas, fontes ou serviços externos;
- sem alteração de regras, modelos, banco ou permissões;
- e-mails de recuperação de senha e nomes técnicos internos não foram
  alterados (pendência para decisão);
- nenhum deploy.
