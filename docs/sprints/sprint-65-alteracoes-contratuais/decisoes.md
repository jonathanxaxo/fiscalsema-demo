# Decisões — Sprint 65

1. O contrato original permanece imutável como referência; alterações vigentes
   formam a posição atual.
2. Valor atual é o valor original mais a soma dos impactos vigentes.
3. Vigência atual é a nova data final da alteração vigente mais recente por
   início de efeitos e identificador.
4. Valor negativo é aceito somente como redução formal e nunca pode tornar o
   valor atual menor que zero.
5. Uma alteração não é excluída: ela pode ser anulada com justificativa.
