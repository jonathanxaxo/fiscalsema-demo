# Decisões — Sprint 33

1. Só o aviso do painel flutuante ficou temporário, como pedido; a faixa de
   demonstração é obrigatória e permanente.
2. O tempo recomeça a cada abertura do painel, para que toda pessoa veja o
   aviso ao começar a conversar.
3. Sem armazenamento no navegador: o comportamento é igual em toda abertura.
